# Yume UI audit

This is a source review of the Expo routes, shared navigation, typography, theme and sheet controls. It also draws on the Android screenshots supplied in this chat. Current layouts, keyboard behavior and frame pacing still need device verification.

## Findings

| Area | What the review found |
| --- | --- |
| Navigation | Showing an inline label only for the selected tab moved neighboring destinations on every switch. The dock now keeps equal slots and labels all four destinations at standard text sizes. Narrow layouts and larger text keep the four icon slots and place the active label below them. |
| Bottom clearance | Scroll content and floating controls previously estimated the dock height differently. The undo toast and Activity shortcut now calculate clearance from the same metrics as the dock, including its larger-text layout. |
| Header hierarchy | Activity and Plan already used 26dp titles, while Reports inherited 34dp. Shared root titles now use 26dp and pushed titles use 24dp, matching Add and Split. |
| Contrast | The dark theme used cream ink on the fixed coral Add button. The button now uses dark foreground ink in both modes. |
